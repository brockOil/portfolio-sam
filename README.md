# Sameer P Bhandiwad Portfolio

A frontend developer portfolio built with React/Vite and Tailwind CSS.
Features a VS Code-style aesthetic with direct, concise copy.

## Project Structure

* `frontend/`: React + Vite frontend mimicking a code editor interface. Portfolio content lives in `frontend/src/data.js`.

## Running the Application

1. `cd frontend`
2. `npm install`
3. `npm run dev`
