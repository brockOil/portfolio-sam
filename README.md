# Sameer P Bhandiwad Portfolio

A fullstack developer portfolio built with React/Vite, Tailwind CSS, and FastAPI.
Features a VS Code-style aesthetic with direct, concise copy.

## Project Structure

* `backend/`: FastAPI application serving portfolio JSON data.
* `frontend/`: React + Vite frontend mimicking a code editor interface.

## Running the Application

### Backend
1. `cd backend`
2. `pip install -r requirements.txt`
3. `uvicorn main:app --reload`

### Frontend
1. `cd frontend`
2. `npm install`
3. `npm run dev`
